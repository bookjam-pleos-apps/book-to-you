# apps

실행되는 세 애플리케이션이다. 부모 웹은 API를 호출하고, 차량 앱은 같은 API에서 책장과 오디오를 받는다.

## 하위 폴더

| 경로 | 역할 |
|---|---|
| [api/](api/README.md) | Hono 기반 API다. 계정·기기 연결·목소리 등록·렌더 요청과 오디오 제공을 담당한다. |
| [vehicle/](vehicle/README.md) | 차량 앱의 실행·빌드·기능 안내다. |
| [web/](web/README.md) | React·Vite 기반 부모 웹이다. 로그인, 차량 연결, 목소리 녹음, 동화 만들기와 듣기 화면이 있다. |
