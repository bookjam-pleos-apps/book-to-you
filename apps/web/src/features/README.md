# features

사용자 기능별 화면과 API 호출이다. feature끼리 직접 import하지 않고 app에서 조합한다.

## 하위 폴더

| 경로 | 역할 |
|---|---|
| `auth/` | 로그인 코드 요청·확인, 약관 동의, 이메일 없는 시작과 계정 관리를 담당한다. |
| `devices/` | 차량 연결 코드 확인과 연결된 기기 관리를 담당한다. |
| `library/` | 동화 목록, 생성 요청, 완성된 책장과 듣기 화면이다. |
| [voices/](voices/README.md) | 목소리 등록과 관리다. 녹음 흐름, 마이크 안내, 목소리 상세·메뉴로 나뉜다. |
