# src

웹 화면과 브라우저 기능의 소스다. 앱 진입점은 app/main.tsx다.

## 하위 폴더

| 경로 | 역할 |
|---|---|
| `app/` | 라우팅과 화면 조합을 담당한다. 서로 다른 feature를 함께 쓰는 화면은 여기에 둔다. |
| `assets/` | 웹 번들에 포함하는 이미지다. |
| [features/](features/README.md) | 사용자 기능별 화면과 API 호출이다. feature끼리 직접 import하지 않고 app에서 조합한다. |
| `lib/` | 브라우저 감지와 마이크 녹음 기능이다. 서버 API와 화면 구성에 의존하지 않는다. |
| `shared/` | 여러 화면에서 쓰는 API 클라이언트, UI, 경로 처리다. |
