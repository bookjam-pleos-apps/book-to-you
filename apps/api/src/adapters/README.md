# adapters

HTTP, DB, 파일, 오디오 도구처럼 외부 시스템과 통신하는 구현이다. 필요한 인터페이스는 application에 있다.

## 하위 폴더

| 경로 | 역할 |
|---|---|
| `cli/` | 명령행 인자와 실행 결과를 처리한다. |
| `content/` | JSON 원고와 녹음 대본 로딩·검증를 담당한다. |
| `db/` | Postgres 연결과 단일 인스턴스 잠금를 담당한다. |
| `demo-bundle/` | 시연 데이터 묶음 파일 읽기·쓰기를 담당한다. |
| `ffmpeg/` | ffmpeg 오디오 변환·신호 측정·챕터 인코딩를 담당한다. |
| `http/` | Hono 앱 구성과 인증·요청 검증·오류 응답를 담당한다. |
| `mail/` | 로그에 로그인 코드를 남기는 개발용 메일러를 담당한다. |
| `model-compose/` | GPU 서비스의 전사·녹음 분석 호출를 담당한다. |
| `polling/` | 작업의 반복 실행과 종료를 관리한다. |
| `queue/` | pg-boss 작업 큐와 보존·삭제 작업 연결를 담당한다. |
| `render-job/` | GPU 렌더 제출·조회와 작업 묶음 전송를 담당한다. |
| `storage/` | S3 및 메모리 객체 저장소를 담당한다. |
