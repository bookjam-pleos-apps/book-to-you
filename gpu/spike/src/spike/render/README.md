# render

동화 한 편을 단위로 나눠 생성하고 잇는다. 이 폴더에는 한 편 렌더의 뼈대(생성, 저장, 문맥 잇기)가 있고, 단위 하나를 다루는 규칙은 하위 폴더에 있다.

## 하위 폴더

| 경로 | 역할 |
|---|---|
| `attempt/` | 단위 하나의 시도를 다룬다. 재시도 정책, 시도 파일 이름, 받아쓰기 QC 판정이다. |
| `batch/` | 여러 단위를 배치로 묶어 라운드마다 생성하고, QC에서 떨어진 단위만 다시 만든다. |
| `tail/` | 단위 끝이 끊기지 않게 꼬리를 붙여 생성한 뒤 꼬리를 잘라 낸다. |
| `voice/` | 인물 녹음 단위의 목소리가 어긋났는지 판정하고 다시 굴리거나 다른 녹음으로 대체한다. |
| `job/` | API와 렌더 서비스가 주고받는 작업 폴더를 읽고 렌더한다. |
| `trials/` | 실험 명령이 쓰는 계획과 기록이다. 길이 사다리, 앞부분 비교, 후보 고르기, 받아쓰기 재채점이다. |

## 파일
